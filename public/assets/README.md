# Foto undangan

Letakkan foto di folder ini dengan nama berikut agar langsung terbaca oleh halaman:

| Nama file | Kegunaan |
| --- | --- |
| `cover-couple.jpg` | Foto pasangan untuk sampul |
| `bride-portrait.jpg` | Potret mempelai wanita |
| `groom-portrait.jpg` | Potret mempelai pria |
| `story-couple.jpg` | Foto untuk bagian cerita |
| `gallery-couple.jpg` | Kolase tiga foto: pasangan, mempelai wanita, dan potong kue |
| `wedding-detail.jpg` | Kolase dua foto: cincin pernikahan dan buket |
| `music.mp3` | Musik latar dalam format MP3 |
| `music.m4a` | Sumber audio AAC sebelum dikonversi ke MP3 |

Jika nama atau format file berbeda, sesuaikan `src` pada `src/data/wedding.js`.
Sesuaikan juga teks `alt` di file tersebut agar cocok dengan isi foto sebenarnya.
Kolase galeri saat ini ditampilkan sebagai beberapa potongan foto terpisah.
Pastikan ekstensi file sesuai format aslinya. Mengganti ekstensi saja tidak mengubah format audio.
